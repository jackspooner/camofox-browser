# Use the Camofox agent browser

Discover tools under the `camofox` MCP alias. Tool names on these pages are
the public names. A host may display them with a prefix such as
`mcp__camofox__`. The live connection's schemas govern available calls.

| I want to… | Start here |
| --- | --- |
| Open a page and see it | [First tab and snapshot](getting-started.md) |
| Click, type, scroll, read or manage tabs | [Browser tools and examples](../tools.md#browser-tools) |
| Pick a native option or activate a focused control | [Select a shipping option and apply it](examples/select-and-press.md) |
| Drag a card, handle or other control | [Choose a drag endpoint](operations/drag_and_drop.md), then [drag the fixture's DRAFT card](examples/drag-a-card.md) |
| Find a control by appearance and inspect it before acting | [Locate and review visual targets](capabilities/visual-targeting.md) |
| Ask a model about visible pixels, a crop or an original image | [Analyse a browser image](capabilities/image-analysis.md) |
| Read text or image metadata inside an iframe | [Bounded reads and iframe refs](../frame-reads.md) |
| Collect images or advance through a sequence | [Verified image collection](../image-collection.md) or [capture and advance](../capture-sequences.md) |
| Reuse a login or resume saved work | [Profiles and sessions](concepts.md), then [session tools](../tools.md#profiles-sessions-and-routing) |
| Watch live, take control or log in by hand | [Viewer and human handoff](../tools.md#viewing-and-visual-targets) |
| Choose an available Proton country for a session | [Routing tools and prerequisites](../tools.md#profiles-sessions-and-routing) |
| Check pending input or recover a stopped operation | [Operation status, retry and Stop](../operations.md) and the [error reference](../tools.md#recovery) |

Jump to the [complete tool and recovery reference](../tools.md) when you know
an operation's name. For repository changes and validation, use the
[development guide](../development/README.md).
